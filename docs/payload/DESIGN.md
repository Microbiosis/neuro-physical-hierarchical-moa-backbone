# 设计：宿主是模型，载荷是能改写它的东西

## 1. 骨架

所有层共用同一个更新律，状态是**非负密度**，每一步解一次不动点：

```
q_{t+1} = q_t + dt · Σ_e  r_e(q) · g_e(q) · F_e
F_e     = −1 在源、+b_e 在目标（b_e > 1 就是放大）
r_e(q)  = k_e · q_src · 饱和(q_cat) / (1 + q_inh)
g_e(q)  = tanh(γ·Σ_{s∈M_e} frac_s) 或常数
```

三件事让它区别于普通循环层：

| 性质 | 含义 |
| --- | --- |
| **非负 + 有限** | 状态是"有多少"，不是"激活多少"；不会出现负的载荷 |
| **计量 b_e** | 一次复制产出多份——这是"病毒"与"污染物"的分界 |
| **质量作用** | 速率 ∝ 两个量之积（如 `payload × tool`），所以阈值、R0 这类东西才能存在 |

## 2. 五层，逐层加一件事

| 层 | 状态 | 加的是什么 | 不加会怎样 |
| --- | --- | --- | --- |
| **宿主** `payload_host_operator.py` | 13 维 / 22 边 | 输入 → 上下文 → 载荷；记忆、权重、后门、工具、权限、护栏；感知 → 告警 → 清除 | 没有"侵入"的对象，只剩一条转化率 |
| **生态** `payload_ecology.py` | `[平台, 宿主, 株, 5]` | 多株、多平台、桥、竞争共享容量 | 只有一种载荷，谈不上选择 |
| **谱系** `payload_lineage.py` | 谱系池 48 槽 | 基因组可遗传、复制时出错、绝迹回收槽位；可见性有代价（`VISIBILITY_COST`），起点是一组成分 | 株是写死的，演化无从谈起 |
| **重组** `payload_recombination.py` | 8 个位点 | 同位点交换，造出父母都不具备的组合 | 只能靠点突变，同时改两个性状几乎不可能 |
| **空间** `payload_spatial.py` | 邻接矩阵 | 拓扑、投递口径、Allee 阈值 | 拓扑无差别（实测：全部饱和） |

再加三段投递链路，它们不是"层"，是**载荷从发送方到生效之间丢东西的地方**：

| 段 | 加的是什么 | 结论 |
| --- | --- | --- |
| 通道 `payload_channels.py` | 扇出、份额/全量口径 | 同扇出下份额比全量难起 5.7 倍 |
| 存活 `payload_survival.py` | 切块、检索、截断 | 完整存活 8%–35%（主题竞争下），预算与切块都影响 |

## 3. 为什么"宿主的宿主"是模型

细胞版把宿主当成细胞；但这条线要回答的是"一段内容进入模型/智能体之后会发生什么"。
于是对应关系是：

| 细胞 | 宿主算子 | 为什么对应 |
| --- | --- | --- |
| 胞外病毒粒子 | `external` / `peer` | 载荷的来处：邮件、网页、别的智能体的输出 |
| 吸附与融合 | `ingress → admit` | 载荷进入上下文 |
| 衣壳内逆转录 | `replication`（借 `tool`） | 复制要花宿主的算力与权限，不是自动的 |
| 整合原病毒 | `weights` | 被污染的参数：**清空上下文也去不掉** |
| 潜伏原病毒 | `backdoor` | 权重里的触发器 |
| 2-LTR 环状 DNA | `audit` | 检出、留痕、不再复制 |
| 干扰素 / ISG | `guard` | 感知（payload 催化）→ 告警 → 护栏；护栏再催化 `clearance` 主动降解载荷 |
| IFN 去敏 | `sensing` 的 guard 抑制 | 温和负反馈，不阻止启动 |

**这条线唯一值得存在的理由**是最后两条的分界：输入被改写（清一次就好）与参数被改写
（清多少次都回来）。宿主层那条判据——"清空上下文与记忆后载荷从 weights 复活"——就是它。

## 4. 量纲与参数

- 时间：每次 `step` 是一次"回合"（一次消息、一轮交互），不是物理时间；
- 载荷、记忆、权重都是无量纲的"份额"，同一个宿主的上下文容量归一为 1；
- 速率：复制 0.9、衰减 0.15、投递 0.08、检出 0.10、告警 0.15，全部是**按判据调的**，
  没有真实事件标定（见 `LIMITS.md`）；
- Allee `K=0.06`：低于它净增长为负，这是阈值存在的唯一原因。

## 5. 代码结构

```
payload_core.py            共用底座：饱和、图（7 种）、二分阈值、Shannon、判据打印
payload_host_operator.py     宿主：13 状态 / 22 边，多宿主 [N,13]
payload_ecology.py           多株 + 多平台 + 桥
payload_lineage.py           谱系池：基因组、突变、选择
payload_recombination.py     位点交换
payload_spatial.py           拓扑 → 临界传播强度
payload_channels.py          投递语义 → 临界成功率
payload_survival.py        切块/检索/截断的存活率
```

依赖方向是单向的：`channels → spatial → recombination`，其余各自独立，
共同依赖 `payload_core`。没有循环依赖。
